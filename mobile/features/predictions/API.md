# Predictions API

| Method | Path | Description |
|---|---|---|
| GET | `/v1/predictions/fight/:id` | Full fight prediction |
| GET | `/v1/predictions/event/:id` | All predictions for an event |
| GET | `/v1/predictions/dashboard` | Dashboard aggregation |
| GET | `/v1/predictions/highlights` | Top highlighted predictions |
| GET | `/v1/predictions/history` | Historical predictions |
| GET | `/v1/predictions/accuracy` | Accuracy stats |
| GET | `/v1/predictions/matchup` | Head-to-head prediction |
| POST | `/v1/predictions/saved/:id` | Save a prediction |
| DELETE | `/v1/predictions/saved/:id` | Unsave a prediction |
| GET | `/v1/predictions/saved` | Saved predictions |
