# Rankings API

| Method | Path | Description |
|---|---|---|
| GET | `/v1/rankings/p4p` | Pound for pound |
| GET | `/v1/rankings/division/:name` | Division rankings |
| GET | `/v1/rankings` | List with filters |
| GET | `/v1/rankings/history/:id` | Fighter rank history |
| GET | `/v1/rankings/goat` | GOAT rankings |
| GET | `/v1/rankings/prospects` | Top prospects |
| GET | `/v1/rankings/movement` | Biggest movers |
| GET | `/v1/rankings/streaks` | Win/loss streaks |
| GET | `/v1/champions` | Current champions |
| GET | `/v1/champions/history` | Champion lineage |
| GET | `/v1/title-defenses` | Title defense records |
| GET | `/v1/elo` | Elo leaderboard |
| GET | `/v1/composite` | Composite leaderboard |
